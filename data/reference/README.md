# Growth reference provenance

Original WHO daily LMS reference, published by CDC: https://www.cdc.gov/growth-chart-training/media/files/WHOref_d.csv

Method: https://www.cdc.gov/growth-chart-training/hcp/computer-programs/sas-who.html

Fetched 18 October 2026. Original file unmodified. SHA256: 709d04e07de554b6e379aa21ede29b14e41946943f62b9fadea9f80c56f1c4d3

Derived JSON uses sex 1/2 and exact integer ages 0 through 730 days, columns weight, recumbent length and head circumference L/M/S in that order. No interpolation or extrapolation. Charts are for full-term infants; preterm comparison is withheld. Standing height comparisons are withheld rather than silently adjusted.
